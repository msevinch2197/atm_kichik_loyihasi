 atm_kichik_loyihasi🏧 Oddiy Bankomat (ATM) — Python

Bu loyiha Python tilida yozilgan oddiy bankomat dasturi bo‘lib, foydalanuvchiga balansni ko‘rish va naqd pul yechish imkonini beradi.

✨ Imkoniyatlar

🔐 Parol orqali kirish

💰 Balansni ko‘rish

💵 Naqd pul yechish (50 000, 100 000, 200 000, 500 000 yoki ixtiyoriy)

📉 3% komissiya hisoblanadi

🚪 Chiqish imkoniyati

⚙️ Boshlang‘ich ma’lumotlar

Parol: 2020

Balans: 200 000 so‘m

Komissiya: 1%

📝 Eslatma

Komissiya har bir pul yechishda olinadi

Balans yetarli bo‘lmasa, xabar beriladi

Dastur o‘quv maqsadida yozilgan
